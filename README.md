# Supplementary Material for

## Foundation Models in Ophthalmic Artificial Intelligence: Current Status and Future Directions

This repository contains the supplementary material associated with the review article:

> **Foundation Models in Ophthalmic Artificial Intelligence: Current Status and Future Directions**

**Published in:** IEEE Journal of Biomedical and Health Informatics (JBHI)  
**DOI:** [10.1109/JBHI.2026.3736832](https://doi.org/10.1109/JBHI.2026.3736832)

## Contents

This repository provides the expanded supplementary table that was not included in the main manuscript due to journal page limitations.

### Table S1. Expanded Technical Comparison of Ophthalmic Foundation Models

This table presents a comprehensive comparison of existing ophthalmic foundation models, covering:

- Model category and name
- Model nature and adaptation strategy
- Architecture and framework
- Pretraining or adaptation objectives
- Vision and language backbone architectures
- Input imaging modalities
- Training data types and quantities
- Downstream tasks and capabilities

The table aims to provide a systematic overview of current ophthalmic foundation models and facilitate further research in ophthalmic artificial intelligence.
